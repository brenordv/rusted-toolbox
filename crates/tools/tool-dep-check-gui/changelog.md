# Changelog

## 1.0.0
- First release: a Rune window over dep-check's engine. Pick an ecosystem, type the packages one
  per line, press Check (or `mod+enter`), and read one row per package with its badge, findings,
  and supply-chain facts, under a line that says what each service did.
- Shares `~/.rusted-toolbox/dep-check/rate-limits.json` with the CLI.
- Logs to `~/.rusted-toolbox/dep-check-gui/logs` at info by default.
